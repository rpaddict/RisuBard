# RisuBard v0.9.99

## [개선] 분석이 빠진 턴을 이어서 BardWiki에 반영
- 자동 분석을 꺼 둔 동안 쌓인 턴은 자동 분석을 다시 켜도 위키에 반영되지 않고, 최신 턴만 분석되었습니다. 이 턴들을 반영하려면 메시지를 하나씩 재분석하거나 리부트해야 했습니다.
- 이제 '추가 분석'을 누르거나 자동 분석이 새 턴을 분석할 때, 마지막으로 분석된 턴 뒤에 빠진 턴이 있으면 '분석되지 않은 턴 N개가 있습니다' 확인 창이 뜹니다.
- 'N턴부터 이어서 분석'을 고르면 빠진 턴부터 오래된 순서로 분석해 기존 위키 위에 쌓습니다. 기존 위키는 지우지 않습니다. 중간에 실패하면 남은 턴은 위키 대기 배너에 남아 다시 시도하거나 건너뛸 수 있습니다.
- 자동 분석에서 빠진 턴이 '몇 턴마다 묶어 분석' 값 안에 들어가면 묻지 않고 한 번에 묶어 분석합니다.
- '최신 턴만 분석'을 고르면 전처럼 최신 턴만 분석합니다. 자동 분석 중에 이렇게 고른 턴은 앱을 다시 열기 전까지 다시 묻지 않습니다.
- 처음부터 위키를 쓰지 않았던 대화의 옛 기록은 묻지 않습니다. 그런 기록은 리부트로 반영하세요.
