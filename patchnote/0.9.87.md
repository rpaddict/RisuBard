# RisuBard v0.9.87

## 응답이 중간에 끊길 때 제공자의 종료 사유 표시
- 응답이 나오다가 중간에 멈추면 "모델 제공자가 응답 생성을 중단했습니다."만 보여서, 안전 필터인지 저작물 인용 차단인지 정책 거절인지 알 수 없었습니다.
- 이제 제공자가 보낸 종료 사유를 함께 보여 줍니다. 예: "모델 제공자가 응답 생성을 중단했습니다. (종료 사유: SAFETY)". Gemini의 SAFETY, RECITATION, PROHIBITED_CONTENT, OpenAI 호환 API의 content_filter, Anthropic의 refusal 등이 그대로 나옵니다.
- 제공자는 어떤 단어가 걸렸는지까지는 알려 주지 않으므로 원인 범위를 좁히는 용도입니다.

## 바드위키 아크 플롯이 앞부분 줄기를 잃지 않음
- 아크 플롯을 갱신할 때 AI가 기존 아크 줄을 통째로 빠뜨리면, 첫 만남처럼 이야기 앞부분의 줄기가 플롯에서 사라질 수 있었습니다. 실제 리부트 측정에서 아크 상한이 남아 있는데도 처음 열여섯 턴 남짓의 줄기가 빠진 사례가 있었습니다.
- 이제 다시 쓴 플롯에 기존 아크의 사건 링크가 하나도 남지 않으면, 그 아크 줄을 원래 글 그대로 아크 개요 맨 앞에 되살립니다. 여러 아크를 합치면서 대표 사건 링크를 남긴 경우는 그대로 둡니다.
- 되살린 경우 턴 영수증에 "스토리 아크 플롯에서 빠진 아크 N개를 되살렸습니다"라고 남습니다.

## 프롬프트 비서와 캐릭터 비서의 시스템 프롬프트 편집
- 환경설정 리스바드 항목의 인풋 도우미 아래에 "비서 프롬프트" 페이지가 생겼습니다. 프롬프트 비서의 답변 프롬프트와 블록 선별 프롬프트, 캐릭터 비서의 분석 프롬프트와 플레이 테스터 프롬프트를 프롬프트 v2 에디터로 고칠 수 있습니다.
- 고친 프롬프트는 목록에 "수정됨"으로 표시되고, "기본값으로 되돌리기"로 언제든 원래 문구로 돌아갑니다. 고치지 않은 프롬프트는 앱이 업데이트될 때 새 기본 문구를 그대로 따라갑니다.
- 프리셋, 봇 자료, 채팅 같은 자료는 지금처럼 프롬프트 뒤에 자동으로 붙습니다. 프롬프트는 적은 그대로 보내며 CBS 문법은 처리하지 않습니다.
- 앱은 프롬프트가 요구하는 태그와 형식(`<read>`, `<edit>`, JSON 등)을 읽어 동작하므로, 이 규칙을 지우면 비서 기능이 제대로 동작하지 않을 수 있습니다.

## 아카라이브 로그 만들기를 범위 확인과 생성 두 단계로 분리
- 이전에는 창을 열자마자 챗 전체로 미리보기를 만들기 시작했고 중간에 멈출 수 없었습니다. 200챗이 쌓인 챗이면 끝날 때까지 기다려야 했고, 실수로 창 바깥을 누르면 창이 닫혀 처음부터 다시 만들어야 했습니다.
- 이제 창을 열면 먼저 "만들 범위" 목록이 바로 나옵니다. 시작 메시지와 끝 메시지는 앞부분을 길게 보여 주므로 범위가 어디서 시작해 어디서 끝나는지 확인할 수 있습니다. 범위를 고친 뒤 "로그 만들기"를 누르면 그때 이미지와 서식을 입혀 로그를 만듭니다.
- 만드는 중에는 "중지" 버튼으로 멈출 수 있고, 창 바깥을 눌러도 창이 닫히지 않습니다.
- 다 만든 메시지는 기억해 둡니다. 중지하거나 창을 닫았다가 다시 열면 목록에 이미 만든 메시지가 체크로 표시되고, "이어서 만들기"로 남은 메시지만 만듭니다. 범위를 좁히거나 넓혀도 이미 만든 메시지는 다시 만들지 않습니다.
- 폰트 크기와 프로필 이미지 설정은 메시지를 다시 만들지 않고 미리보기에 바로 반영됩니다. 같은 이미지가 여러 메시지에 반복되면 한 번만 불러옵니다.

## 바드위키 작업 취소 버튼이 채팅 입력을 가리지 않음
- 바드위키가 작업하는 동안 "바드위키 작업 취소" 버튼이 입력줄 위로 떠 있어서 입력칸 오른쪽 위의 글자를 가렸습니다.
- 이제 취소 버튼은 바드위키 버튼 왼쪽에 같은 크기의 빨간 정지 버튼으로 나타납니다. 작업 중에만 보이며 기능은 그대로입니다. 버튼에 마우스를 올리면 "바드위키 작업 취소"라고 나옵니다.

## 파이어폭스에서 봇 버튼이 두 번 실행되던 문제 수정
- 파이어폭스에서 봇이 메시지에 넣은 버튼(`risu-btn`, `risu-trigger`)을 누르면, 버튼이 실행한 스크립트가 메시지를 다시 그린 뒤 같은 클릭이 새로 그려진 버튼에 한 번 더 닿아 동작이 두 번 실행될 수 있었습니다. 순환 버튼이 한 칸이 아니라 두 칸씩 넘어가는 식이었습니다.
- 이제 같은 누름에서 다시 그려진 같은 버튼은 한 번만 실행합니다. 다른 버튼을 누르거나 키보드로 다시 누르는 것은 그대로 동작합니다.
