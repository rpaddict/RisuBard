# RisuBard v0.9.25

## [BardWiki] 조회 시간 제한

- **느린 연결 대응:** 위키 조회 제한 시간을 전역·챗별 1~10,000ms 범위에서 조절할 수 있고 기본값을 10초로 늘렸습니다. 과거 원문 재조회와 위키 리부트에도 같은 설정을 안전하게 적용합니다.

## [BardWiki] 짧은 입력 문맥 폴백

- **후보 0건 방지:** 짧은 행동·반응 입력에서 직접 후보를 찾지 못하면 최근 대화의 끝부분을 제한된 범위에서 조회어로 사용해 현재 장면과 관련된 위키를 불러옵니다.

## [호환성] OpenAI 구조화 출력

- **첫 요청 400 수정:** `stateChanges.before`의 nullable 스키마를 OpenAI strict structured output이 허용하는 형식으로 바꿔 불필요한 실패와 재시도를 없앴습니다.

## [호환성] Gemini HypaV3 요약

- **assistant 종결 요청 수정:** HypaV3 사용자 ChatML 요약 요청이 assistant 메시지로 끝나면 user 지시 턴을 덧붙여 Gemini 계열 모델의 요청 제약을 충족합니다.
