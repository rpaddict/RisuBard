# RisuBard v0.9.49

바드페인터에 AI가 변경하지 않는 표현 조각을 추가하고, 초안 화면과 저장 반응을 개선했습니다. 프리셋 변경과 채팅 고정 적용 문제를 수정하고 바드위키 의미 분석의 Gemini 호환성도 보완했습니다.

## [기능] 바드페인터 표현 조각

- **표현 조각 관리:** `관리` 창에서 자주 쓰는 프롬프트를 생성, 편집, 저장, 복제, 삭제하고 한 번의 클릭으로 메인 블록에 추가할 수 있습니다. 추가한 조각은 직접 편집하거나 휴지통 버튼으로 제거할 수 있으며, AI의 초안 작성과 개선은 조각 내용을 변경하지 않습니다.
- **초안 블록 정리:** `화풍`을 첫 블록으로 배치해 네거티브 프롬프트를 함께 표시하고, 별도의 추가 표현과 장면 네거티브 입력칸을 없앴습니다. `메인 블록`도 접을 수 있으며, 표현 조각은 기본적으로 접어 두고 제목을 클릭해 펼치며 안내는 섹션 제목의 툴팁으로 확인할 수 있습니다.

## [성능] 바드페인터 저장과 이미지 응답

- **저장 반응 개선:** 표현 조각, 프리셋, 생성 설정과 이미지 결과를 저장할 때 불필요한 전체 호환 DB 재생성과 중복 파일 동기화를 줄였습니다. 실제 데이터 저장 완료 확인과 실패 시 복구는 유지합니다.
- **이미지 응답 처리:** 이미지 바이너리 전체를 거대한 JSON 로그로 변환하던 작업을 없애 이미지 응답 후 화면이 멈추는 부담을 줄였습니다.

## [안정성] 프리셋 변경과 채팅 고정

- **삭제 후 설정 잔류:** 사용 중인 프리셋을 삭제하면 대체 프리셋의 프롬프트, 토글, 모듈 연동을 즉시 적용하고 이전 설정이 대체 프리셋에 저장되지 않도록 수정했습니다. 삭제된 프리셋의 채팅 바인딩도 해제합니다.
- **프리셋 변경 유지:** 프롬프트가 바인딩된 채팅에서 다른 프리셋을 선택하면 바인딩도 함께 변경하여 이전 프리셋으로 되돌아가지 않도록 수정했습니다.
- **채팅 진입 시 적용:** 사이드바를 숨겼거나 채팅을 나중에 불러오는 경우에도 고정한 프롬프트를 적용합니다. 별도로 저장한 채팅별 토글 값은 유지합니다.

## [안정성] 바드위키 의미 분석

- **PageFold Gemini 호환성:** 구형 모델 이름과 번호가 붙지 않은 연결에서도 첫 의미 분석 요청부터 호환 형식을 적용합니다. 구조화 출력 오류 뒤 재시도하느라 분석이 지연되던 문제를 수정했으며, 결과의 저장 전 검증은 유지합니다.
