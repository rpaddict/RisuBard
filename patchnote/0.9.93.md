# RisuBard v0.9.93

## [추가] 독자 게시판에 외전 탭
- 본편과 별도로 IF 루트나 캐릭터 외전을 같은 게시판에 연재할 수 있습니다. 외전은 탭으로 나뉘고, 1화부터 따로 번호를 매깁니다.
- 본편을 복사한 챗에서 게시판을 열면 `외전으로 연재` 버튼이 보입니다. 탭과 외전 제목만 정하면 됩니다. 이미 연결된 챗에서는 연재 막대의 `연재 위치` 옆 `바꾸기`로 고릅니다.
- 본편 챗을 열면 자동으로 본편에 이어서 연재합니다. 예를 들어 본편 20화에서 갈라진 IF를 10화 올린 뒤 본편 챗으로 돌아가면, 다음 화는 21화로 올라갑니다.
- 독자는 본편과 외전을 모두 읽은 것으로 기억합니다. 외전 내용을 본편에서 일어난 일로 착각하지는 않지만, 두 이야기를 비교하는 반응은 할 수 있습니다.
- 외전을 다 쓰면 `완결`을 누릅니다. 완결 알림이 올라가고, 완결된 외전은 그 챗을 되감아도 내려가지 않습니다. 같은 탭에 다른 챗으로 새 외전을 이어 연재할 수 있습니다.
- 한 챗에서 IF를 쓴 뒤 갈림길까지 되감고 연재 위치를 본편으로 바꿔도, 외전 화는 그대로 남습니다.
- 게시판 위의 `전체`, `본편`, 외전 탭으로 글을 나눠 볼 수 있습니다. 외전 화의 점수는 본편 평균과 이전 작품 비교에 섞이지 않습니다.
- 외전 챗을 지워도 게시판에 올라간 외전 화의 요약과 댓글은 남습니다.

## [수정] 둥근 스킨에서 부분 편집 창이 잘리고 응답이 둘로 나뉘어 보이던 문제
- `둥근 기본`, `히어로 코믹 (둥근)` 스킨에서 응답의 일부를 골라 편집할 때 편집 창이 메시지 카드 영역 밖으로 잘리던 문제를 고쳤습니다.
- 같은 스킨에서 긴 응답이 입력창 위에서 위아래 두 덩어리로 갈라져 보이던 문제도 고쳤습니다.
- 원인은 0.9.92에서 넣은 효과였습니다. 화면보다 긴 메시지 카드를 화면 가장자리에서 둥글게 깎으려고 카드 전체를 잘라 냈는데, 그 바람에 카드 안에서 뜨는 창까지 함께 잘렸습니다. 이 효과를 없앴습니다. 카드 자체의 둥근 모서리는 그대로입니다.
- 스킨 제작자용 `tokens`의 `message-clip-radius`는 이제 효과가 없습니다. 0.9.92용으로 만든 스킨도 그대로 설치됩니다.

## [수정] 일부 모델에서 독자 게시판이 "JSON을 찾지 못했습니다"로 실패하던 문제
- 생각 과정을 응답 앞에 붙여 보내는 모델이나 프로바이더에서 독자 명단과 반응 생성이 `모델 응답에서 JSON을 찾지 못했습니다`로 실패하던 문제를 고쳤습니다. 생각 과정 속 JSON 초안이나 중괄호가 본 답과 섞여 읽히던 것이 원인이었습니다.
- 이제 `<Thoughts>`, `<think>` 블록을 먼저 걷어 내고, 응답 안에서 짝이 맞는 JSON 덩어리 중 마지막 것을 답으로 씁니다. 문자열 안에 줄바꿈을 그대로 넣은 응답도 읽습니다.

## [개선] 폰과 태블릿에서 모듈, 플러그인 목록을 한 화면에 더 많이
- 모듈과 플러그인 목록이 폰과 태블릿에서는 제목만 보여 줍니다. 소개문이 몇 줄씩 차지하던 자리를 없애, 폰 세로 화면에서 한 번에 보이는 모듈이 3개 남짓에서 7~9개로 늘었습니다. 소개문은 그대로 검색되고, 마우스를 쓰는 넓은 화면에서는 한 줄로 줄여 보여 줍니다.
- 폭이 넉넉하면 목록이 2열이나 3열로 나뉩니다. 설정 창을 넓게 키우면 모듈 12개가 3열로 한 화면에 다 들어옵니다.
- 폰 세로 화면에서는 폴더 목록이 `전체`, `미분류`, 폴더 이름을 나란히 놓은 한 줄로 줄어듭니다. 고른 폴더 옆에만 이동, 이름 바꾸기, 삭제 버튼이 나옵니다.
- 가로로 눕힌 화면에서는 폴더가 목록 위가 아니라 옆에 놓이고, 행 높이와 여백도 줄어듭니다. 채팅 화면의 모듈 창에서는 가로 폰 기준 3개에서 5개 정도로 늘었습니다.
- 선택 해제, 이동, 삭제 같은 선택 도구는 항목을 하나 이상 골랐을 때만 목록 아래에 떠서 나타납니다. 고르지 않았을 때는 검색창과 추가 버튼만 한 줄에 남습니다. 프롬프트 프리셋 목록 위에 늘 펼쳐져 있던 `보이는 항목 선택`, `선택 해제`, 폴더 이동 줄도 이 막대로 옮겼습니다.
- 폰에서 프롬프트 프리셋 목록은 항목마다 한 줄로 줄었습니다. 행마다 있던 위, 아래 버튼은 좁은 화면에서 숨기고, 대신 항목을 고르면 뜨는 막대의 위, 아래 버튼으로 순서를 바꿉니다. 여러 개를 골라 한꺼번에 옮길 수도 있습니다.
- 높이가 낮은 태블릿 가로 화면에서는 설정 페이지의 안내 문구와 위쪽 여백을 줄여 목록에 높이를 더 줍니다.
