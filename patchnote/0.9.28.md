# RisuBard v0.9.28

저장 런타임을 검증된 0.9.25 V1 구조로 되돌리고, V2 세이브는 원본을 건드리지 않는 별도 변환기로 가져오도록 바꿨습니다. 캐릭터 삭제 뒤 RisuRealm과 캐릭터 전환이 오래 멈추던 문제를 수정하면서 0.9.26 이후의 저장 구조와 무관한 편집·그리모어·안정성 개선은 유지했습니다.

## [안정성] V1 저장 구조 복귀

- **검증된 저장 경로:** 앱의 저장·로딩·인덱스 동작을 0.9.25의 V1 파일 구조로 복귀했습니다. V2 저장 구조와 자동 이관 코드는 앱 실행 경로에서 제거했습니다.
- **분리된 V2 변환:** V2 원본을 읽기 전용으로 검사하고 존재하지 않는 별도 목적지에 V1 변환본을 만드는 도구를 추가했습니다. 설정·캐릭터·대화·메시지·초안·자산·KV와 원본 전체 해시를 대조한 뒤에만 결과를 확정합니다.
- **간단한 변환 실행:** Windows에서는 V2 폴더를 `V2-to-V1.bat`에 끌어다 놓기만 하면 원본 옆에 V1 결과를 만듭니다. Termux는 한 줄 명령으로 기본 데이터 변환과 V1 서버 시작을 함께 처리하며, Linux·macOS도 원본 경로 하나만 지정하면 됩니다. 자세한 방법은 [V2 세이브를 V1 구조로 변환하기](../docs/ko/v2-to-v1-conversion.md)에서 확인할 수 있습니다.

## [안정성] 캐릭터 삭제 후 전환 복구

- **대기 상태 해제:** 닫힌 BardWiki 창이 캐릭터 전환 중 디스크 조회를 시작하지 않게 했습니다. 캐릭터를 삭제한 뒤 RisuRealm을 열거나 다른 캐릭터로 전환할 때 수 분 동안 로딩이 이어지던 원인을 제거했습니다.

## [기능] 그리모어 검색과 진단

- **검색 정확도:** 직접 언급한 이름과 키를 우선하고, 이어쓰기나 짧은 입력에서도 마지막 유효 사용자 입력을 사용하도록 검색 후보 구성을 개선했습니다.
- **전체 검색:** 로어북 검색에서 이름·키·본문을 한 번에 찾을 수 있으며, 해석된 검색 입력과 후보 제외 이유를 진단 화면에서 확인할 수 있습니다.
- **긴 로어 진단:** 분석 입력 한도를 넘는 로어를 구분해 표시하고, BardChat 직접 분석 명령에도 설정된 토큰 한도를 적용합니다.

## [편의성] 제작과 대화 편집

- **빌더 작업 공간:** 로어·페르소나 빌더의 긴 원문과 수정본을 스크롤하거나 세로 크기를 조절할 수 있고, 분할 크기와 작업 상태를 유지합니다.
- **프롬프트 V2 편집:** 선택한 블록 또는 모든 블록에서 문구를 찾아 바꿀 수 있으며, 연속 입력 반응성과 미리보기 커서·간격을 개선했습니다.
- **편집 상태 유지:** 지난 메시지를 바로 본문 끝에서 편집할 수 있고, 저장 뒤에도 열린 로어북 폴더와 하이파 표시 설정을 유지합니다.
- **모듈 조작:** 채팅 모듈의 활성화 버튼을 작고 빠르게 조작할 수 있는 형태로 정리했습니다.

## [안정성] 로그와 위키 저장

- **로그 복구:** 외부 변경으로 시스템 로그 체크섬이 달라져도 안전하게 다시 읽어 서버가 시작 단계에서 종료되지 않도록 했습니다.
- **위키 저장 재시도:** 정본 문서 일부를 저장하지 못한 턴을 완료로 처리하지 않고, 성공한 결과를 보존하면서 실패한 부분을 다시 시도합니다.

## [보안] 설치별 로그인 키

- **키 자동 갱신:** 이전 포터블에 포함될 수 있던 공통 로그인 키를 설치별 새 키로 교체합니다. 세이브와 비밀번호는 유지되며 업데이트 후 다시 로그인해야 할 수 있습니다.

## [호환성] 포터블 접속 주소

- **기본 포트 통일:** Linux·macOS 포터블 실행기의 기본 접속 포트를 서버와 같은 `7777`로 맞췄습니다.
