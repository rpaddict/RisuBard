# RisuBard v0.9.24

이번 버전은 지금까지 추가된 핵심 창작 기능을 처음 보는 사용자도 한눈에 이해할 수 있도록 소개 문서를 보강했습니다.

## [문서] RisuBard 주요 기능 소개

- **핵심 기능 총정리:** v0.8.4부터 v0.9.23까지의 패치노트에서 BardWiki, Grimoire, 제작 작업대, 서사 저장과 공유 등 굵직한 기능을 골라 접이식 아카라이브용 소개 문서로 정리했습니다.

## [UI] 프롬프트 v2 본문 선택 표시

- **조건 블록 범위 개선:** 비주얼 모드에서 조건과 적용 본문을 연속된 배경·굵은 하단 테두리로 묶고 중첩 조건의 들여쓰기를 강화해 그 외 분기까지 분명하게 구분합니다. 헤더를 누르면 본문 전체를 접고 펼칠 수 있으며, 조건 원문은 별도로 확인합니다. 스위치 조건은 켜짐·꺼짐으로, 논리 연결은 그리고·또는으로 표시합니다.

- **기존 토글 조건 표시:** 개요 블록의 `#when::토글::tis::값` 조건도 실제 토글 라벨로 표시합니다. 미리보기용 빌드에 누락됐던 조건 분리기 수정도 반영했습니다.

- **텍스트 선택 정렬:** `프롬프트 v2`에서 본문을 드래그로 선택할 때 색상 미리보기와 선택 영역이 어긋나는 문제를 수정했습니다. 긴 본문의 줄바꿈과 마지막 빈 줄까지 스크롤한 위치도 일치하도록 맞췄습니다.
- **본문 검색어 이동:** 블록 검색창의 화살표 버튼이나 `Enter`로 현재 선택한 블록의 검색어 위치를 바로 선택하고 스크롤할 수 있습니다. 반복해서 누르면 다음 검색어로 이동하며 마지막 위치에서는 처음으로 돌아갑니다.
- **창 안에 고정된 작업 영역:** 상위 프레임의 리사이즈 핸들과 불필요한 상단 여백을 없애고 설정 창의 남은 너비와 높이 안에서 작업 영역을 전부 사용합니다. 긴 프롬프트 목록과 사이드바 미리보기는 각 패널 안에서 따로 스크롤되며, 현재 프롬프트 버튼은 페이지 제목과 같은 행에 배치했습니다.
- **빠른 블록 편집:** 목록 제목 옆에서 선택 블록 아래에 새 블록을 만들거나 그대로 복제할 수 있습니다. 본문 열에서는 블록 이름을 바로 눌러 수정하고 타입·특수 타입·역할을 같은 행에서 바꿀 수 있습니다.
- **편집 크기 기억:** 프롬프트 본문 입력창의 높이와 마지막 편집 모드를 다시 열거나 새로고침한 뒤에도 유지합니다.
- **조건 비주얼 편집:** 활성화 조건과 조건문 디자이너는 툴바 왼쪽, `원문`과 `비주얼` 전환은 오른쪽에 배치하고 불필요한 블록 설정 버튼을 제거했습니다. 비주얼 모드에서도 미리보기 토글값에 따라 조건 본문이 활성 색이나 흐린 비활성 색으로 바뀝니다. 조건문을 커서에 삽입하거나 선택 본문을 감싸면 디자이너가 자동으로 닫히며, 알 수 없는 구문은 경고와 함께 원문 그대로 보존합니다.

## [UI] 모듈 목록 선택과 드래그 수정

- **선택 버튼 정렬:** 모듈·플러그인 항목 왼쪽의 선택 버튼을 항목 높이의 중앙에 맞췄습니다.
- **모듈 작업 버튼 정리:** 모듈 오른쪽의 활성화·페르소나·편집·삭제 버튼을 폴더 사이드바와 같은 작은 크기와 스타일로 줄이고, 한 줄로 배치해 세로 중앙에 맞췄습니다.
- **모듈 편집 화면 통일:** 모듈 생성·수정 화면에 공통 설정 카드와 액센트 탭을 적용했습니다. 수정 화면 하단에는 중복된 적용 버튼을 없애고 다운로드·캐릭터 변환을 탭과 같은 크기의 액센트 버튼으로 중앙 배치했으며, 제목 왼쪽의 화살표 버튼이나 `Esc`로 설정창을 닫지 않고 모듈 목록으로 돌아갈 수 있습니다.
- **폴더 이동 복구:** 모듈·플러그인·프롬프트 프리셋 목록에서 드래그할 때 금지 커서가 표시되며 폴더 이동과 순서 변경이 막히던 문제를 수정했습니다.
- **챗 모듈 선택 개선:** 메인 챗의 모듈 창을 폴더·검색이 있는 새 관리 UI로 교체하고 화면 중앙에 맞춰 사이드바 때문에 창이 밀리던 문제를 수정했습니다. 편집·페르소나 할당·모듈 삭제 버튼 대신 `전체`와 `챗` 라벨 아래 정사각형 아이콘 버튼을 두고 켜진 상태는 밝은 액센트 배경으로 표시하며, 두 범위는 독립적으로 저장됩니다.

## [UI] 시작 화면 개선

- **한국어 로딩 안내:** UI 언어가 한국어이면 시작 화면과 저장 파일·플러그인 로딩 단계도 한국어로 표시합니다.
- **RisuBard 시작 로고:** 시작 화면의 로딩 안내 위에 둥근 모서리의 RisuBard 로고와 현재 버전을 표시합니다. 로고 이미지를 다른 화면 리소스보다 먼저 요청해 초기 로딩부터 바로 나타나도록 개선했습니다.

## [BardWiki] 리부트 실패 복구

- **누락 방지:** 리부트 중 API 재시도를 모두 소진하거나 정본 문서 저장에 실패하면 해당 배치를 완료 처리하지 않고 멈춥니다. `리부트 계속`을 누르면 안전 체크포인트에서 같은 배치를 다시 실행합니다.

## [BardWiki] 위키링크 원인 표시

- **미해결 상태 구분:** 마크다운 미리보기에서 연결된 문서가 없는 링크는 회색 점선, 제목·별칭이 여러 문서와 겹친 링크는 경고색 물결 밑줄로 표시합니다. 링크를 클릭하거나 키보드로 선택하면 문서 없음 또는 충돌한 문서 목록을 바로 확인할 수 있습니다.
