# RisuBard v0.9.31

프롬프트 V2 편집과 BardWiki 탐색을 다듬고, 외부 프로그램으로 세이브 파일을 안전하게 편집할 수 있게 했습니다. 중단된 분석을 복구하고 Windows용 RisuBard 자체 업데이트가 실패할 때 구버전으로 되돌아가는 문제도 바로잡았으며, 구형 백업과 대용량 캐릭터 카드 호환성도 강화했습니다.

## [기능] 프롬프트 V2 블록 편집

- **블록 단위 이동:** `비주얼` 모드에서는 제목 표시줄을 드래그해 조건 블록끼리 순서를 바꿀 수 있으며 본문 텍스트 선택은 유지됩니다. 정밀한 행 단위 편집은 `원문` 모드에서 할 수 있고, 모드를 전환해도 보고 있던 상대 위치가 유지됩니다.
- **제목 중심 목록:** 채팅 프롬프트 V2의 왼쪽 목록에서 본문 미리보기·타입·상태 배지를 숨기고 행 간격과 선택 배경을 통일했습니다. 긴 프리셋에서도 블록 제목을 한눈에 살펴볼 수 있습니다.
- **에디터 반응 속도:** 행 사이 삽입 위치를 계속 계산하던 동작을 없애고 숨겨진 탭의 편집기를 즉시 정리합니다. 검색하지 않을 때는 목록의 불필요한 본문 해석과 상태 계산도 생략합니다.

## [기능] 외부 세이브 편집

- **저장 일시 정지:** 좌측 메뉴의 모래시계 버튼으로 브라우저 저장을 잠시 멈추고 프롬프트 프리셋·로어북 파일을 외부 프로그램에서 편집할 수 있습니다. 외부 작업이 끝나면 파일을 검증하고 최신 내용을 다시 불러와 작업을 이어갑니다.

## [편의성] BardWiki 탐색과 요청 확인

- **본문 검색과 강조:** 문서 사이드바 상단에서 본문을 검색해 일치하는 문서만 볼 수 있고, 선택한 문서에서는 검색어를 편집기와 Markdown 미리보기에 강조합니다. 문서·링크 상태 라벨은 사이드바 하단으로 옮겼습니다.
- **요청 상세 표시:** 모델 SDK를 통해 전송한 일부 요청에서 상세 정보가 빠지던 문제를 수정했습니다. 시스템 요청 로그에서 해당 요청의 URL·헤더·본문도 확인할 수 있습니다.

## [안정성] 분석과 편집 화면 복구

- **불완전한 분석 보존:** AI 분석 응답이 일부 잘리거나 불완전해도 정상 항목과 회수 가능한 초안을 보존합니다. 문제 항목은 빨간색으로 표시하며 해당 항목만 다시 분석할 수 있습니다.
- **창 밖 드래그 보호:** 최대 너비를 화면 좌우 여백 안으로 제한해 리사이즈 핸들이 화면 밖으로 나가지 않도록 했습니다. 크기를 조절하다 창 밖에서 마우스를 놓아도 관리자가 닫히지 않습니다.

## [안정성] 업데이트 실패 복구

- **구버전 복귀 방지:** Windows에서 RisuBard나 원격 접속을 켠 채 업데이트해 파일 교체가 실패하면, 새 화면 일부만 적용됐다가 다음 시도에서 이전 버전으로 돌아가던 문제를 수정했습니다. 이제 업데이트 전에 종료해야 할 프로그램을 안내하고, 도중에 실패해도 기존 설치 상태를 즉시 복구합니다.

## [호환성] 백업과 파일 가져오기

- **구형 백업 복원:** 구형 RisuAI 백업의 대용량 에셋을 처리하다 업로드가 중간에 멈추던 문제를 수정하고 처리 상태를 표시합니다.
- **PocketRisu 백업 호환:** BardWiki·원고가 포함된 일반 RisuBard 백업도 PocketRisu(포켓리스)에서 파일명 문제로 복원이 거부되지 않도록 개선했습니다. 이전 백업 형식도 계속 불러올 수 있습니다.
- **백업 선택 안내:** PocketRisu나 다른 RisuBard 설치본으로 옮길 때는 일반 전체 백업을 사용하도록 화면을 정리했습니다. 데이터가 일부 제외되는 원본 RisuAI 호환 내보내기는 레거시 도구로 구분했습니다.
- **대용량 캐릭터 카드:** 애니메이션 WebP 등 큰 에셋이 포함된 캐릭터 카드를 가져올 수 있도록 에셋당 크기 제한을 100MiB로 늘렸습니다.
