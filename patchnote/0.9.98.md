# RisuBard v0.9.98

## [보안] 서버가 이 PC에서만 접속을 받음
- 지금까지 리스바드 서버는 주소를 정하지 않고 열려 유선, 무선 등 PC의 모든 네트워크에서 접속을 받았습니다. 공유기나 방화벽이 막지 않으면 다른 기기나 외부에서 리스바드를 열어 저장된 API 키를 쓸 수 있었습니다.
- 이제 기본으로 이 PC(`127.0.0.1`)에서만 접속을 받습니다. `http://localhost:7777` 접속, 설정의 원격 접속(Quick Tunnel), Tailscale은 그대로 동작합니다.
- 같은 와이파이의 휴대폰 등에서 `http://PC의IP:7777`로 직접 열어 쓰던 분은 서버를 켜기 전에 환경변수 `RISUBARD_HOST=0.0.0.0`을 설정해야 합니다. 이렇게 열면 서버 창에 경고가 표시됩니다. 되도록 원격 접속 기능이나 Tailscale을 쓰세요.
- Docker 이미지는 컨테이너 밖에서 접속해야 하므로 계속 모든 주소에서 받습니다. 외부 노출이 걱정되면 `docker-compose.yml`의 포트를 `127.0.0.1:7777:7777`로 바꾸세요.
