# RisuBard v0.9.23

v0.9.23의 핵심은 복잡한 채팅 프롬프트를 한 화면에서 설계하고 검증하는 데스크톱용 `프롬프트 V2`입니다. 기존 프롬프트 형식을 그대로 유지하면서 블록 조건, 커스텀 토글과 실제 사이드바 미리보기를 연결해 프리셋 제작 과정을 크게 단순화했습니다.

## [기능] 프롬프트 V2 워크벤치

- **3패널 통합 편집:** 프롬프트 블록 목록, 선택한 블록의 편집 화면, 실제 채팅 사이드바 형태의 토글 미리보기를 한 화면에 배치했습니다. 각 패널은 필요에 따라 숨기거나 다시 열 수 있습니다.
- **블록 활성화 조건:** 블록마다 여러 조건을 추가하고 `AND` 또는 `OR`로 결합할 수 있습니다. 각 조건은 변수값과 같을 때뿐 아니라 다를 때도 블록을 활성화하도록 설정할 수 있습니다.
- **실시간 조건 미리보기:** 오른쪽 미리보기에서 토글이나 드롭다운 값을 바꾸면 블록 활성화 상태와 본문 안의 `if_pure`·`if`·`when` 분기가 즉시 파란색 또는 흐린 회색으로 표시됩니다. 미리보기 값은 프리셋별로 보존되며 버튼 하나로 초기화할 수 있고, 실제 채팅 설정에는 영향을 주지 않습니다.
- **토글 변수 마스터 목록:** 기존 커스텀 토글 구성을 한곳에서 확인하고 편집하며, 필요한 변수명을 곧바로 복사해 블록 조건이나 프롬프트 본문에 사용할 수 있습니다.
- **기존 프리셋 완전 호환:** 새 블록 조건은 기존 CBS 조건문으로 저장되며 별도 데이터 형식을 요구하지 않습니다. 본문에 직접 작성한 조건문도 그대로 보존되어 블록 자체의 활성화 조건과 함께 사용할 수 있습니다.
- **데스크톱 작업 공간 개선:** 세 패널의 헤더 높이를 통일하고 불필요한 세로 크기 제한을 없애 긴 프롬프트도 넓게 편집할 수 있게 했습니다. 좁은 화면에서는 기존 프롬프트 편집 환경을 계속 사용할 수 있습니다.
