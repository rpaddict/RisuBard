# RisuBard v0.9.96

## [수정] 스트리밍 응답이 끝날 때까지 화면에 안 보이던 문제
- 스트리밍으로 응답을 받는 동안 새 메시지 칸만 뜨고 본문이 비어 있다가, 응답이 끝나야 한 번에 나타나던 문제를 고쳤습니다. 이제 받는 대로 바로 표시됩니다.
- 도중에 다른 버튼을 누르거나 화면을 바꾸면 그제야 본문이 나타나던 것도 같은 문제였습니다. `콘텐츠 갱신 중 읽던 위치 유지`가 켜져 있거나(기본값) 스트리밍 표시 최적화를 쓸 때 일어났습니다.

## [수정] 플러그인 모델 스트리밍
- 레거시 모델 설정에서 플러그인 프로바이더 모델(유미프로바이더 등)을 쓰면, 프로바이더가 스트리밍으로 응답해도 화면에는 다 받은 뒤 한 번에 표시되던 문제를 고쳤습니다. 이제 프로바이더의 스트리밍 설정을 따라 글이 실시간으로 나옵니다.
- 원인은 레거시 설정의 응답 스트리밍 체크였습니다. 플러그인에 따라 이 체크박스가 보이지 않을 수 있는데도, 꺼져 있으면 스트림을 모아서 표시했습니다.
