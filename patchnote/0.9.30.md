# RisuBard v0.9.30

긴 대화 탐색과 챗별 BardWiki 작업 흐름을 크게 다듬었습니다. Grimoire 검색, 프롬프트 V2 편집, 백업과 원격 접속도 더 편하고 안전해졌습니다.

## [기능] 현재 챗에서 BardWiki 관리

- **챗별 설정 작업 공간:** 현재 챗의 설정을 작동 방식·검색·분석/응답·정본 작성으로 나눠 관리할 수 있습니다. 챗 규모에 맞춘 도움말을 확인하고, 현재 값을 전역 기본값으로 적용하거나 창 크기를 조절해 기억할 수 있습니다.
- **과거 응답 재분석:** AI 응답 아래의 돋보기 버튼을 누르면 해당 턴과 이전 문맥을 현재 위키 설정으로 다시 분석합니다. 빠진 사건은 복구하되 캐릭터의 최신 상태는 과거 내용으로 덮어쓰지 않습니다.
- **분석 입력 제어:** 응답 생성과 별도로 BardWiki 분석에서 사용자 메시지를 제외할 수 있으며, 현재 챗에만 다른 값을 적용할 수도 있습니다.
- **검색 결과 재정렬:** 점수가 비슷한 검색 후보를 바드쨩이 한 번 더 정렬할 수 있습니다. 이 보조 작업이 실패하거나 결과가 올바르지 않으면 기존 검색 순서를 그대로 사용합니다.
- **Wiki Prompt V2 편집:** 위키 프롬프트에서도 원문·비주얼 편집, 조건 설정, 토글 미리보기와 찾기·바꾸기를 사용할 수 있습니다. 기본 프리셋은 보호되며 복제본만 편집할 수 있습니다.

## [기능] Grimoire 검색·분석 강화

- **첫 메시지부터 검색:** 새 챗의 첫 메시지에 나온 장소와 인물도 검색 단서로 사용해 장면에 맞는 로어와 주변 인물을 찾습니다.
- **직접 언급 우선:** 현재 입력에서 직접 언급한 항목을 우선하고, 댓글과 비활성 메시지는 검색에서 제외합니다. 어떤 후보가 제외됐는지도 도움말에서 확인할 수 있습니다.
- **분석 분류 개선:** 상태창과 필수 출력 형식은 필수 규칙으로, 긴 인물 명부와 타임라인은 검색 가능한 개별 항목으로 정리합니다. 장소·소속 관계는 근거가 있을 때만 주변 인물 연결로 제안합니다.
- **분석 지시문 확인:** 환경설정과 AI 메타데이터 분석 창에서 실제 Grimoire 분석 지시문을 확인할 수 있습니다. 기본값은 보호되고 복제본만 수정할 수 있으며, 시작된 분석은 당시 지시문을 끝까지 사용합니다.
- **분석 창 공간 활용:** 숫자 설정을 두 열로 정리하고 설정·요청 계획 사이에 크기 조절 막대를 추가했습니다. 대상 목록도 남는 화면 높이를 더 잘 활용합니다.

## [편의성] 긴 대화 탐색

- **페이지·턴 바로가기:** 메시지 입력창 위 세이브/로드 툴바 오른쪽에서 페이지와 그 페이지 안의 AI 응답 순번을 지정해 바로 이동할 수 있습니다. 입력한 턴이 마지막 응답을 넘으면 해당 페이지의 마지막 응답으로 이동합니다.
- **고정 가능한 네비게이터:** `환경설정 > 환경 > 접근성 > 스크롤`에서 사이드 네비게이터를 항상 보이도록 고정할 수 있습니다.
- **응답 턴 번호:** 각 AI 응답의 위아래에 같은 턴 번호를 표시해 긴 대화에서도 메시지를 쉽게 찾고 참조할 수 있습니다.

## [편의성] 프롬프트와 토글 편집

- **편집 위치 기억:** 설정 탭이나 `프롬프트 블록`·`토글 구성` 사이를 오가도 마지막 블록, 편집 모드와 스크롤 위치를 복원합니다.
- **토글 사용처 탐색:** 각 토글 변수의 사용 횟수를 보여 주고, 사용처를 누르면 해당 블록과 줄로 바로 이동합니다.
- **조건 블록 조작:** 비주얼 모드에서 조건 블록 전체를 드래그해 옮기거나 잘라내고 삭제할 수 있습니다.
- **고정 토글 갱신:** 사이드바의 고정된 토글에서 `현재 설정으로 덮어쓰기` 또는 고정 해제를 선택할 수 있습니다. 덮어쓰면 현재 선택값과 되돌리기 기준이 함께 갱신됩니다.
- **스타일 프리셋 복원:** 페르소나·로어 빌더에서 선택한 스타일 지시 프리셋을 창을 다시 열거나 앱을 재실행해도 유지합니다.
- **본문 겹침 해소:** 조건이 적용된 본문을 클릭해 편집할 때 미리보기와 원문 글자가 겹치지 않습니다.

## [편의성] 챗 시작과 파일 가져오기

- **페르소나 이어받기:** 같은 캐릭터에서 새 챗을 만들면 이전 챗의 유효한 페르소나를 이어받습니다. 이전 챗이 없으면 마지막 전역 페르소나로 시작합니다.
- **모듈 적용 범위 명확화:** 채팅 안 모듈 창의 `챗` 버튼은 현재 캐릭터의 기존·새 챗 전체에 적용되며, 개별 챗에 저장된 기존 설정은 덮어쓰지 않습니다.
- **드래그해서 가져오기:** 모듈·프롬프트 프리셋·JavaScript 플러그인·캐릭터 파일을 앱 창에 놓아 가져올 수 있습니다. 파일 종류에 맞는 위치로 가져오고 진행·완료·실패 상태를 안내합니다.

## [UI] 작업 진행 상태 표시

- **로딩 상태 안내:** Realm 조회와 로컬 이미지 읽기의 진행·실패·시간 초과를 화면 오른쪽 아래에서 확인할 수 있습니다. 시작 로고가 너무 일찍 사라지는 깜빡임도 줄였습니다.

## [안정성] 저장·파일·원격 접속

- **원격 접속 복구:** 네트워크 환경에 맞춰 Cloudflare 연결 방식을 자동 선택하고, 터널 연결이 확인된 뒤에만 QR 코드와 링크를 표시합니다. 연결이 끊기면 재시도를 안내하고, Android Firefox의 DNS 문제에는 해결할 설정 경로를 보여 줍니다.
- **불완전한 모듈 차단:** 잘린 모듈이나 에셋 수가 맞지 않는 모듈을 일부만 가져오지 않습니다. 내보낼 이미지가 없을 때 빈 파일을 정상 에셋처럼 넣는 문제도 막았습니다.
- **안전한 불러오기 확인:** 현재 챗을 덮어쓰는 불러오기 확인창이 세이브 창 위에 표시되며, 확인하기 전에는 불러오기 버튼이 로딩 상태로 바뀌지 않습니다.
- **조용한 저장 표시:** 짧은 저장에는 아이콘을 띄우지 않고, 오래 걸리는 저장만 작은 고정 아이콘으로 표시합니다.

## [시스템] 백업과 저장 기반 정리

- **백업 도구 통합:** 전체·설정 전용 백업과 복원, 업스트림 호환 백업, 저장 폴더 가져오기·정리, 부분 백업과 데이터셋 내보내기를 `시스템 > 백업`에 모았습니다.
- **기존 경로 호환:** 예전 이전 메뉴를 열면 시스템 백업 탭으로 자동 이동하며, 기존 V1 백업 기능을 그대로 사용할 수 있습니다.
- **저장 성능 측정 기반:** 저장 결과나 내용은 바꾸지 않고 처리 시간과 쓰기 규모만 기록해, 이후 저장 성능을 단계적으로 개선할 수 있게 준비했습니다.
