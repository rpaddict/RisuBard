# RisuBard v0.9.95

## [추가] 사이드바 미니멀 모드
- 캐릭터 사이드바 상단의 공유 버튼 왼쪽에 미니멀 모드 버튼을 추가했습니다. 누르면 채팅 아래의 모델과 바인딩 영역이 짧게 정리되고, 다시 누르면 원래대로 돌아갑니다. 켠 상태는 저장되어 다음에 열어도 유지됩니다.
- 모델 모드는 메인 모델, 보조 모델 선택과 설정 버튼을 한 줄에 놓습니다. 그 아래 줄에는 메인 모델과 보조 모델이 나란히 놓입니다.
- 페르소나 바인딩, 프롬프트 바인딩, 채팅별 프리셋 고정은 제목 없이 한 줄에 모았습니다. 페르소나는 썸네일 버튼 하나로 표시되고, 이미지가 없으면 이름 첫 글자를 보여 줍니다.
- 각 버튼을 누르면 작은 메뉴가 열립니다. 바인딩 변경과 해제는 이 메뉴에서 합니다.
  - 페르소나 메뉴: `새 챗 생성시 페르소나 고정`을 켜고 끌 수 있습니다.
  - 프롬프트 메뉴: `프롬프트 파라미터 사용`을 켜고 끌 수 있습니다. 켜져 있으면 버튼에 조절 아이콘이 표시됩니다.
  - 채팅별 프리셋 고정 메뉴: 현재 설정으로 덮어쓰기, 고정한 프리셋 값으로 되돌리기, 토글 프리셋 열기를 할 수 있습니다.
- 미니멀 모드에서는 채팅별 토글이 격자로 놓입니다. 사이드바 폭에 맞춰 한 줄에 들어가는 만큼 같은 너비로 채워집니다.
  - 켜고 끄는 토글은 제목이 적힌 버튼이 되어, 누를 때마다 켜지고 꺼집니다. 켜진 버튼은 바인딩 색으로 표시됩니다.
  - 선택형과 짧은 입력 칸은 칸 위에 작은 글씨로 제목을 보여 줍니다.
  - 그룹은 그대로 접고 펼 수 있고, 그룹 안의 항목도 격자로 놓입니다. 긴 입력 칸, 설명문, 구분선은 한 줄을 통째로 씁니다.
  - 탈옥 토글은 첫 토글 줄에 함께 놓입니다.
  - 채팅별 프리셋 고정 뒤에 값을 바꾼 항목에는 모서리에 작은 점이 표시됩니다.
  - 긴 제목은 칸 안에서 말줄임으로 줄고, 마우스를 올리면 전체 제목이 보입니다.

## [추가] 버튼 효과음
- `설정 > 소리 및 알림`에 `버튼 효과음` 항목을 추가했습니다. 앱 전체의 버튼, 메뉴, 스위치, 드롭다운, 탭, 링크와 사이드바의 클릭 가능한 줄을 누르거나 마우스를 올릴 때 짧은 소리가 납니다. 기본값은 켜져 있습니다.
- 클릭음은 누르는 순간 납니다. 기본 클릭음은 `딸깍` 하는 짧은 소리입니다.
- 클릭음과 호버음은 따로 켜고 끌 수 있고, 볼륨도 조절할 수 있습니다. 각 항목 옆의 재생 버튼으로 미리 들어 볼 수 있습니다.
- 소리 파일을 직접 올려 클릭음과 호버음을 바꿀 수 있습니다. 버튼 효과음 목록은 응답 알림음 목록과 따로 관리되어, 알림용 효과음은 섞이지 않습니다.
- 호버음은 마우스에서만 납니다. 터치 화면에서 두 번 울리지 않게 하기 위해서입니다. 버튼 사이를 빠르게 지나가면 일부만 울리고, 응답을 생성하는 동안에는 나지 않습니다.
- 비활성 버튼과 글자 입력 칸에서는 소리가 나지 않습니다. 키보드로 버튼을 눌러도 클릭음이 납니다.

## [개선] 부분 수정 창이 본문 너비에 맞게 열림
- 응답을 마킹해서 여는 부분 수정 창이 본문 영역을 넘어가 바드위키 같은 사이드바에 가려지던 문제를 고쳤습니다. 이제 창이 해당 메시지 본문과 같은 위치, 같은 너비로 열리고, 사이드바보다 위에 표시됩니다.
- 창의 왼쪽이나 오른쪽 가장자리를 끌어서 너비를 조절할 수 있습니다. 화면 밖으로는 늘어나지 않습니다.
- 수정할 위치를 고르는 창과 삭제 확인 창도 본문 영역에 맞춰 열립니다.
- 블록 부분 수정을 켜 두었을 때 마우스를 움직이면 화면에 보이는 메시지 수만큼 같은 계산을 반복하던 것을 고쳤습니다. 이제 마우스 아래 메시지 하나만 계산하므로, 긴 채팅에서 마우스 이동과 스크롤이 가벼워집니다.

## [개선] 화면 컴파일 메시지 정리

- 시작 메뉴가 화면을 컴파일할 때 수백 줄씩 나오던 파일 목록과, 동작과 무관한 경고 메시지가 더 이상 표시되지 않습니다. 이제 진짜 문제가 있을 때만 메시지가 나옵니다.

## [수정] 시작 메뉴로 서버를 켤 때 "서버 실행 실패"가 잘못 뜨던 문제

- 서버가 정상으로 켜지는데도 시작 메뉴 창에 "서버 실행 실패"가 표시되던 것을 고쳤습니다. 이제 서버가 실제로 응답할 때까지 기다린 뒤 브라우저를 엽니다.
- 시작이 너무 오래 걸릴 때 나오는 안내도 더 이상 쓰지 않는 로그 폴더 대신 리스바드 서버 창을 확인하라고 알려 줍니다.
