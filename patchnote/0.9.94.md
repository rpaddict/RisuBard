# RisuBard v0.9.94

## [수정] 일부 모델에서 바드위키가 `AI 응답 형식이 올바르지 않습니다`로 멈추던 문제
- 일부 모델과 프로바이더에서 위키 분석이 `AI 응답 형식이 올바르지 않습니다. 검증되지 않은 내용은 저장하지 않았습니다. (Model output must contain exactly one JSON object)`로 멈추던 문제를 고쳤습니다.
- 정본 본문처럼 여러 줄짜리 항목에 줄바꿈을 이스케이프하지 않고 그대로 넣은 응답을 JSON으로 읽지 못하던 것이 원인이었습니다. 이제 이런 응답도 읽습니다.
- 응답 중간에 끼어 있는 `<Thoughts>`, `<think>`, `<thinking>` 생각 블록과 그 안의 JSON 초안도 건너뜁니다. 응답 앞의 설명문에 닫히지 않은 따옴표가 있어 본 답을 놓치던 경우도 고쳤습니다.
- 답이 여러 개이거나 하나도 없으면 지금처럼 저장하지 않고 멈춥니다.
