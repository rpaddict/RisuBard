# RisuBard v0.9.88

## 메시지 편집 버튼이 눌러도 반응하지 않던 문제
- 응답이 새로 오거나 리롤, 삭제로 메시지 목록이 다시 그려진 뒤, 그 전부터 있던 메시지의 편집 버튼을 눌러도 아무 일도 일어나지 않는 경우가 많았습니다. 다른 봇으로 갔다가 돌아와야 다시 눌렸습니다.
- 메시지 목록을 갱신하는 도중에 메시지를 붙이던 방식 때문에, 목록이 다시 그려질 때 기존 메시지가 화면 갱신 대상에서 빠지는 일이 있었습니다. 이제 메시지를 목록 갱신이 끝난 직후에 붙여, 목록이 몇 번 다시 그려져도 편집 버튼이 바로 반응합니다.

## 부분 백업 실패 시 원인을 알려 주도록 개선
- 로컬 부분 백업 중 서버에서 채팅 하나를 읽지 못하면 `fetchChatContent page error: 500`처럼 상태 코드만 보여 주고 멈춰서, 어느 채팅이 왜 문제인지 알 수 없었습니다.
- 이제 실패한 캐릭터와 채팅 이름, 서버가 알려 준 사유(예: 콜드 스토리지 복원 실패)를 함께 보여 줍니다. 채팅을 직접 열다 실패할 때의 오류에도 서버 사유가 붙습니다.
